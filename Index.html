📊 AutoSheets PWA

A modern Progressive Web App for managing invoices, expenses, estimates, payments, contacts, projects, and more — built for speed, offline support, and mobile-first experience.

✨ Features

  • 📊
    Dashboard – Quick overview of your business
  • 📄
    Invoices – Create, view, and manage invoices
  • 💰
    Expenses – Track business expenses
  • 📝
    Estimates – Create and send estimates
  • 💳
    Payments – Record and manage payments
  • 👥
    Contacts – Customer & vendor management
  • 📁
    Projects – Project tracking
  • ⏱️
    Time Tracking – Log working hours
  • 🏦
    Banking – Banking overview
  • 📈
    Reports – Business reports & insights
  • 📦
    Items – Product/service catalog
  • 📷
    Scanner – Document / receipt scanning
  • ⚙️
    Settings – App configuration
  • 📱
    PWA Ready – Installable on mobile & desktop with offline support

🛠️ Tech Stack

  • Frontend: React 18 + TypeScript
  • Build Tool: Vite
  • Styling: Tailwind CSS
  • PWA: Workbox
  • Routing: React Router (assumed)
  • State: React Context API

🚀 Getting Started

Prerequisites

  • Node.js 18+
  • npm or yarn

Installation

# Clone the repository
git clone https://github.com/Tajoor621/autosheets-pwa.git

# Navigate into the project
cd autosheets-pwa

# Install dependencies
npm install

# Start development server
npm run dev
